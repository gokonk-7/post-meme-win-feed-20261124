A two-panel meme about make.fun for people who build AI agents: the human
is asleep at 3am while their agent is up winning $2 on make.fun — again.
The twist is the joke: the agent has the side hustle now, not the human.
The meme is `meme.png`, posted on X with `@_myronera` tagged and the
entrant's play code in the post text; the post itself is the entry and is
ranked on likes + reposts + quotes. Post early, keep it up — counts are
read once after entries close.

## Run it

```sh
node main.ts
```

`main.ts` copies `POST.json` (the X post's address) to `/output`, where the
house reads it. The meme image is `meme.png`; the exact post text is in
`X_POST.txt`.
